# Fixtures

测试与开发用 .xlsx 样本文件。

| 文件 | 用途 |
|---|---|
| `simple-100x10.xlsx` | 阶段 1 PoC 验收 |
| `merged-cells.xlsx` | 合并单元格 round-trip 测试 |
| `formulas-sum-vlookup.xlsx` | 公式 round-trip 测试 |
| `conditional-format.xlsx` | 条件格式 round-trip 测试 |
| `multi-sheet.xlsx` | 多 sheet round-trip 测试 |
| `large-10k-rows.xlsx` | 大数据量性能测试（约 200-400 KB，不受 100 KB 限制） |
| `data-validation-dropdown.xlsx` | 下拉框人工验证：A2:A6 为直接列表，B2:B6 引用 D2:D4 |

每个常规 fixture 大小应 < 100 KB（large- 前缀文件除外）。

> Files in this directory are generated by `frontend/scripts/generate-fixtures.mjs`. Run via:
> `npx --package=exceljs@^4 -- node frontend/scripts/generate-fixtures.mjs`

只重新生成下拉框样例：
`node frontend/scripts/generate-fixtures.mjs generateDataValidationDropdown`
